## Archive survival rule

A project is **archive-safe enough to retire its worker chat** when a fresh runtime can identify:

1. the project/repo and current exact work subject;
2. the source/effect/qualification claim ceiling;
3. outstanding reviews/dependencies;
4. protected-effect boundary;
5. Bus route or durable coordination pointer;
6. the next runnable frontier;
7. how to fresh-check mutable state.

The matrix is a locator, not authority. Project-local source/PR/receipt remains the controlling evidence for each row.
