# Exodus Runtime Lane Reconstruction V1

Status: SOURCE CONTRACT / NON-ACTIVATING / CHAT-INDEPENDENT

This contract records the durable meaning of chat-local execution labels that have been used in Vera work. It prevents a retired conversation, browser tab, or old Bus branch from becoming identity or authority infrastructure.

## General rule

A lane label is an execution role unless a separate current durable identity contract explicitly says otherwise.

A ChatGPT conversation, Work task, CLI/API session, model invocation, subagent, or browser tab is a terminal. It may instantiate a lane temporarily. The terminal is not the lane's durable identity, memory, authority, assignment, or currentness.

A Bus branch is coordination provenance. Branch existence does not prove that a lane is currently assigned, active, attuned, authorized, or required.

The intended persistent ChatGPT interfaces are exactly:

## Failure behavior

If a fresh runtime cannot establish lane meaning, current assignment, exact subject, authority ceiling, current route, and durable result destination from current durable state, classify WORKER_RECONSTRUCTION_GAP and stop at that boundary. Do not recover the missing pieces from remembered chat content.

This contract grants no merge, deployment, provider mutation, credential/permission change, training, canonical-memory write, Slack activation, or other protected effect.
